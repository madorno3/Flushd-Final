Flush'd

Flush'd is a bathroom locator app that gives detailed information about the closest NYC restrooms to you.

Flush'd uses New York City's api which can be found at: 
https://data.cityofnewyork.us/resource/i7jb-7jku.json

Features:

- Create an account
- Uses user location to find the 5 closest restrooms. It includes information like hours, whether or not the bathrooms are operational, accessiblity, etc.
- Provides directions and maps using Google. Directions change based on mode of transportation.
- Users can leave reviews and rate the bathrooms cleanliness 1-5 toilets

Tech Stack:

Frontend
- React
- JavaScript
- CSS
- Google Maps API

Backend
- Flask
- SQLAlchemy
- PostgreSQL/PostGIS
- JWT Authentication
